### 2.1 敏感词过滤器实现

**文件**: `untils/sensitive.go`
**算法**: DFA (Deterministic Finite Automaton) 确定性有限自动机
**库**: `github.com/importcjj/sensitive`

```go
type SensitiveFilter struct {
    filter *sensitive.Filter
}

// 单例模式
var sensitiveFilter *SensitiveFilter

func GetSensitiveFilter() *SensitiveFilter {
    if sensitiveFilter == nil {
        sensitiveFilter, _ = NewSensitiveFilter("./mgc.txt")  // 词典文件
    }
    return sensitiveFilter
}

// 检查是否包含敏感词
func (sf *SensitiveFilter) ContainsSensitiveWord(text string) bool {
    return sf.filter.Filter(text) != text  // DFA O(n)复杂度
}

// 替换敏感词
func (sf *SensitiveFilter) ReplaceSensitiveWords(text string, replaceWith rune) string {
    return sf.filter.Replace(text, replaceWith)
}
```

### 2.2 DFA算法特点

| 特性 | 说明 |
|------|------|
| 时间复杂度 | O(n)，n为文本长度，与敏感词数量无关 |
| 空间复杂度 | 与敏感词词典规模相关 |
| 匹配方式 | 正向最大匹配 |
| 词库格式 | `./mgc.txt`，每行一个敏感词 |
