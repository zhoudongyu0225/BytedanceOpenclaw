## 一、为什么合规是生死线

### 1.1 监管高压态势（2025-2026）

2025年以来，国家网信办、广电总局对直播行业持续高压：

| 监管文件 | 核心要求 | 生效时间 |
|----------|----------|----------|
| 《互联网直播服务管理规定》修订版 | 弹幕/礼物须审核，平台连带责任 | 2025年7月 |
| 《网络直播营销管理办法》 | 直播间不得出现诱导打赏 | 2025年3月 |
| 未成年人网络保护条例 | 禁止向未成年人提供付费服务 | 2025年1月 |
| 《网络信息内容生态治理规定》 | 弹幕实时审核，AI+人工双重过滤 | 持续执行 |
| 直播平台内容安全专项 | 礼物系统须有反赌机制 | 2025年Q4 |

**现实案例警示**：
- 2025年Q4，某头部直播间因弹幕含赌资信息被处以**500万元罚款**
- 2025年，多款小游戏因扭蛋机制**概率不透明**被下架整改
- 2026年1月，某弹幕游戏因**未成年人充值**问题被媒体曝光，开发者承担连带责任

### 1.2 抖音平台合规要求

抖音作为核心发布平台，对弹幕小游戏有额外要求：

```
违规等级处罚：
├── 严重违规（触及红线）：封禁直播间 + 下架游戏 + 账号拉黑
├── 一般违规（违反规定）：警告 + 限流 + 功能限制
└── 轻微违规（细节瑕疵）：通知整改（通常48小时内）
```

**弹幕小游戏红线清单**：
1. ❌ 禁止弹幕中出现真实货币兑换信息
2. ❌ 禁止礼物价值与游戏内货币双向兑换
3. ❌ 禁止概率性玩法（扭蛋/抽卡）不公示概率
4. ❌ 禁止针对未成年人投放广告
5. ❌ 禁止诱导用户重复高频打赏

```

│  - 正则表达式过滤（广告链接、联系方式）                   │

│  第三层：人工审核（异步，兜底）                            │
│  - 关键词触发人工复核                                    │
```

```go
// AI语义审核接口设计（对接第三方或自建）
type AITextModeration struct {
    endpoint string  // 审核服务地址
    apiKey   string
}

type ModerationResult struct {
    Pass          bool     // 是否通过
    Category      string   // 违规分类
    Confidence    float64  // 置信度 0-1
    SuggestAction string   // 建议操作：block/warn/pass
}

func (ai *AITextModeration) Check(content string) (*ModerationResult, error) {
    // 调用AI审核服务
    payload := map[string]string{"text": content}
    body, _ := json.Marshal(payload)
    
    req, _ := http.NewRequest("POST", ai.endpoint+"/moderate", bytes.NewReader(body))
    req.Header.Set("Authorization", "Bearer "+ai.apiKey)
    req.Header.Set("Content-Type", "application/json")
    
    resp, err := http.DefaultClient.Do(req)
    if err != nil {
        return nil, err
    }
    defer resp.Body.Close()
    
    var result ModerationResult
    json.NewDecoder(resp.Body).Decode(&result)
    return &result, nil
}
```

```go
            RequireRealNameForDanmu: true,
            MinorMaxDanmuPerDay:     20,
            MinorMaxGiftPerDay:      10,
```

```go
// 时间段控制
func (mp *MinorProtection) IsInNightBan(openId string) bool {
    level, _ := mp.GetUserProtectionLevel(openId)
    if level == 0 {
        return false  // 成人不受限制
    }
    
    now := time.Now()
    currentHour := now.Hour()
    
    if level >= 2 {
        // 未成年：22:00-8:00禁用
        if currentHour >= mp.config.NightBanStart || currentHour < mp.config.NightBanEnd {
            return true
        }
    }
    
    return false
}

func CheckDanmuPermission(openId string, content string) (bool, string) {
```

### 4.4 冷静期与消费限额

```go
// 消费风控配置
type ConsumptionControl struct {
    // 单笔消费超过此值触发冷静期（单位：元）
    CalmThreshold float64 = 100
    
    // 冷静期时长（秒）
    CalmPeriodSeconds int = 900  // 15分钟
    
    // 每日消费上限（未成年人）
    MinorDailyLimit float64 = 50
    
    // 每日消费上限（成人）
    AdultDailyLimit float64 = 2000
}

type UserConsumptionRecord struct {
    OpenId           string
    Date             string  // YYYYMMDD
    TotalSpent       float64 // 今日已消费（元）
    LastLargePurchase int64  // 上次大额消费时间戳
    IsInCalmPeriod   bool
}

func (cc *ConsumptionControl) CheckAndApply(openId string, amount float64) (bool, string) {
    // 1. 实名认证查询年龄
    age := douyinAPI.GetUserAge(openId)
    
    // 2. 检查每日上限
    record := cc.GetTodayRecord(openId)
    if age < 18 && record.TotalSpent+amount > cc.MinorDailyLimit {
        return false, fmt.Sprintf("今日额度已用完，未成年人每日消费上限%d元", int(cc.MinorDailyLimit))
    }
    if age >= 18 && record.TotalSpent+amount > cc.AdultDailyLimit {
        return false, "今日消费已达上限，请明日再来"
    }
    
    // 3. 检查冷静期
    if amount*10 >= cc.CalmThreshold { // 抖币/10=元
        if record.IsInCalmPeriod {
            remaining := cc.CalculateRemainingCalmTime(record)
            return false, fmt.Sprintf("冷静期中，还需等待%.0f分钟", remaining/60)
        }
        // 触发冷静期
        record.IsInCalmPeriod = true
        record.LastLargePurchase = time.Now().Unix()
        cc.SaveRecord(record)
    }
    
    return true, ""
}
```
