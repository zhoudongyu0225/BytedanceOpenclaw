## 一、Cocos Creator 3.8 程序化动画详解

### 1.1 动画组件核心功能

Cocos Creator 3.8 提供了强大的程序化动画控制能力，通过 Animation 组件管理动画状态：

| 方法 | 功能说明 |
|------|----------|
| play() | 播放指定动画，未指定则播放 defaultClip |
| crossFade() | 平滑过渡动画，支持淡入淡出效果 |
| pause() | 暂停所有动画 |
| resume() | 恢复播放 |
| stop() | 停止所有动画 |

### 1.2 动画事件系统

支持多种事件回调：

- **PLAY**: 动画开始播放
- **STOP**: 动画停止
- **PAUSE**: 动画暂停
- **RESUME**: 动画恢复
- **LASTFRAME**: 播放到最后一帧（循环次数 > 1）
- **FINISHED**: 动画播放完成

```typescript
import { Animation } from 'cc';

// 骨骼动画事件监听
skeletalAnimation.on(Animation.EventType.FINISHED, this.onAnimationFinished, this);

// 普通动画事件监听
animation.on(Animation.EventType.FINISHED, this.onAnimationEvent, this);
```

### 1.3 帧事件实现

```typescript
// 在脚本中添加帧事件
const { defaultClip } = animation;
defaultClip.events = [
    {
        frame: 0.5,      // 第0.5秒触发
        func: 'onTriggered',  // 回调函数名
        params: [0]     // 传递参数
    }
];
animation.clips = animation.clips;  // 触发更新
```
