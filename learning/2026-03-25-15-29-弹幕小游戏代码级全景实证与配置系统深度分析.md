### 5.3 敏感词过滤器健壮性问题
```go
// sensitive.go
func GetSensitiveFilter() *SensitiveFilter {
    if sensitiveFilter == nil {
        sensitiveFilter, _ = NewSensitiveFilter("./mgc.txt")
        // ⚠️ 问题：初始化失败时返回nil，调用方无nil检查会panic
    }
    return sensitiveFilter
}
```

**风险：** 如果mgc.txt不存在，`GetSensitiveFilter()`返回nil，但`ContainsSensitiveWord()`会直接调用`sf.filter.Filter()`导致panic。

**建议修复：**
```go
func GetSensitiveFilter() *SensitiveFilter {
    if sensitiveFilter == nil {
        sf, err := NewSensitiveFilter("./mgc.txt")
        if err != nil {
            zlog.Logger.Warn().Msg("敏感词过滤器初始化失败，降级为无过滤模式")
            // 创建空过滤器避免nil panic
            sensitiveFilter = &SensitiveFilter{filter: sensitive.New()}
        } else {
            sensitiveFilter = sf
        }
    }
    return sensitiveFilter
}
```

```protobuf
message MessageList {
  string type = 1;          // 消息类型：chat/gift/like
  repeated Message msgList = 2;  // 消息列表
  string AccountId = 3;      // 账号Id（主播）
  string RoomId = 4;        // 房间号

message Message {
  string type = 1;          // 消息类型
  string name = 2;          // 用户昵称
  string uid = 3;           // 用户OpenId
  string head_img = 4;      // 头像URL
  string content = 5;       // 弹幕内容（chat类型）
  string count = 6;         // 点赞数量（like类型，string需转int）
  string total = 7;        // 礼物总价值（gift类型）
  string giftId = 8;       // 礼物ID（string需转int）
  string giftCount = 9;    // 礼物数量
  string giftName = 10;    // 礼物名称
  string repeatEnd = 11;   // 重复结束标记
  string msgId = 12;        // 消息唯一ID（去重用）
  string anchorId = 13;    // 主播ID
  string groupId = 14;     // 群组ID
  bool repeatEndhh = 15;   // 重复结束布尔标记
}
```

**关键风险：** 所有数值字段（count/giftId/total/giftCount）均为string类型，代码中需要大量`StirngToInt32()`转换，存在转换失败导致0值的风险。

```protobuf
message TipsNotify {
```
