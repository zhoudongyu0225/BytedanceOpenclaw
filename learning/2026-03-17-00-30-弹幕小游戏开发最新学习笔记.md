## 二、VeADK-Go 技术深入

### 2.1 Agent 类型与使用场景

根据 VeADK-Go 技能文档：

| Agent类型 | 导入路径 | 适用场景 |
|-----------|----------|----------|
| LLM Agent | `veagent "github.com/volcengine/veadk-go/agent/llmagent"` | 基础智能体，LLM自主决策 |
| Sequential Agent | `.../sequentialagent` | 强制按顺序执行多个子任务 |
| Loop Agent | `.../loopagent` | 循环执行任务 |
| Parallel Agent | `.../parallelagent` | 并行执行多个子任务 |

### 2.2 Agent 定义规范

```go
// LLM Agent 定义示例
subAgent, err := veagent.New(&veagent.Config{
    Config: llmagent.Config{
        Name:        "agent_name",
        Description: "描述",
        Instruction: "指令",
    },
    ModelName: "模型名",
})

// 根智能体（必须命名为 rootAgent）
rootAgent, err := veagent.New(&veagent.Config{
    Config: llmagent.Config{
        Name:        "root",
        Description: "根智能体",
        SubAgents: []agent.Agent{subAgent},  // 包含子Agent
    },
})
```

### 2.3 结构化输出配置

通过 `model_extra_config={"response_format": ...}` 实现结构化输出：

```python
from pydantic import BaseModel

class Step(BaseModel):
    explanation: str  # 步骤说明
    output: str       # 步骤计算结果

agent = Agent(
    instruction="你是一位数学辅导老师",
    model_extra_config={"response_format": Step},
)
```

## 五、性能优化策略

### 5.1 资源加载优化

- 资源懒加载：按需加载游戏资源
- 对象池复用：减少对象创建销毁开销
- 纹理压缩：ASTC/ETC2 格式

### 5.2 网络通信优化

- 断线重连机制：保证连接稳定性
- 数据压缩传输：减少带宽占用
- 心跳保活：及时发现连接断开

### 5.3 渲染优化

- 减少 DrawCall：合并渲染批次
- 合批渲染：降低 GPU 负载
- 遮挡剔除：跳过不可见对象渲染
