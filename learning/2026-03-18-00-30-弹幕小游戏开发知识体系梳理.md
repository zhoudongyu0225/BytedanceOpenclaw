## 二、弹幕系统核心实现

### 2.1 弹幕消息流程

```
用户发送弹幕 → 平台服务器 → WebSocket → 游戏服务端 → 游戏客户端 → 渲染展示
```

### 2.2 核心代码结构

```typescript
// 弹幕管理器
export class DanmuManager {
    private danmuQueue: Danmu[] = [];
    private maxDisplay: number = 50;
    
    // 接收弹幕
    onDanmuReceived(data: DanmuData) {
        const danmu = this.parseDanmu(data);
        this.danmuQueue.push(danmu);
        this.checkOverflow();
    }
    
    // 渲染弹幕
    update(deltaTime: number) {
        for (const danmu of this.displayingDanus) {
            danmu.x -= danmu.speed * deltaTime;
            if (danmu.x < -danmu.width) {
                this.removeDanmu(danmu);
            }
        }
    }
}
```

### 2.3 性能优化策略

| 策略 | 实现方式 | 效果 |
|------|----------|------|
| 对象池 | 预创建弹幕对象 | 减少GC |
| 限频 | 每秒最多显示N条 | 避免卡顿 |
| 层级管理 | 按优先级渲染 | 重要信息优先 |
| 视口剔除 | 只渲染可见区域 | 提升帧率 |

**1. 弹幕点歌**

- 发送特定指令参与游戏

**3. 礼物PK**
- 礼物触发特效
- 两边主播PK机制
- 增强竞争和互动

**4. 答题互动**
