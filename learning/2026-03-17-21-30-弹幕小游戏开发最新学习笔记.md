## 二、Cocos Creator 3.8 核心技术

### 2.1 程序化动画系统

Cocos Creator 3.8 引入的程序化动画是重点升级：

```typescript
import { Animation, SkeletalAnimation } from 'cc';

// 骨骼动画控制
const skeletalAnimation = this.node.getComponent(SkeletalAnimation)!;
skeletalAnimation.play('idle');

// 动画状态切换
skeletalAnimation.crossFade('run', 0.3);

// 普通动画
const animation = this.node.getComponent(Animation)!;
animation.play('attack');

// 帧事件监听
animation.on(Animation.EventType.FINISHED, () => {
    console.log('动画播放完成');
});
```

**优势：**
- 完全代码控制，适合弹幕游戏动态效果
- 状态机切换平滑
- 帧事件精确触发游戏逻辑

## 三、VeADK-Go 实战指南

### 3.1 快速入门配置

**环境要求：**
- Go 1.24.4+

**最小化配置 (config.yaml)：**
```yaml
model:
  agent:
    provider: openai
    name: doubao-seed-1-6-250615
    api_base: https://ark.cn-beijing.volces.com/api/v3/
    api_key: # 火山引擎ARK API Key
```

**安装：**
```bash
go get github.com/volcengine/veadk-go
```

### 3.2 运行模式

```bash
# 命令行模式
go run agent.go

# Web界面模式
go run agent.go web api webui

# 大模型超时配置
go run agent.go web -read-timeout 3m -write-timeout 3m api webui
```

### 3.3 弹幕游戏AI应用场景

### 4.2 性能优化要点

| 优化方向 | 具体措施 | 预期效果 |
