## 二、性能优化实战技巧

### 2.1 网络层面优化

#### 消息压缩
- JSON → Protobuf 减少30%-50%流量
- 增量更新只传输变化部分
- 消息合并批量发送

#### 协议优化
```typescript
// 弹幕消息结构优化示例
interface DanmuMsg {
  type: number;      // 1=文本 2=礼物 3=系统
  uid: string;       // 用户ID
  content: string;   // 弹幕内容
  timestamp: number; // 时间戳
  vip: boolean;      // 是否VIP
  badge: string;     // 徽章ID
}

// 使用Protobuf压缩后
message DanmuProto {
  fixed32 type_uid = 1;  // 合并压缩
  bytes content = 2;
  fixed64 timestamp = 3;
  uint32 flags = 4;      // vip+badge合并
}
```

### 2.2 渲染层面优化

#### Canvas渲染优化
- **离屏Canvas预渲染**：复杂图案先画在离屏Canvas
- **脏矩形渲染**：只重绘变化区域
- **requestAnimationFrame同步**：与显示刷新同步

#### WebGL渲染优化
- **SpriteBatch批处理**：相同纹理的弹幕合并渲染
- **Shader优化**：简化计算，使用低精度
- **实例化渲染**：大量相同对象使用实例化

#### 内存管理
- **对象池**：弹幕对象回收复用
- **弱引用**：缓存不常用的资源
- **分帧加载**：大量弹幕时分批处理

### 2.3 客户端优化策略

#### 弹幕数量限制
- 屏幕内最多显示条数限制（如100条）
- 超出部分进入排队队列
- 相同用户弹幕频率限制

#### 降级策略
- 高峰期降低弹幕透明度
- 简化弹幕特效
- 关闭部分动画效果

## 三、高并发场景处理

### 3.1 流量分级策略

| 弹幕量级 | 处理策略 |
|----------|----------|
| < 1000/s | 正常处理，全量展示 |
| 1000-5000/s | 客户端采样，服务端过滤 |
| 5000-10000/s | 服务端限流，分通道推送 |
| > 10000/s | 优先展示高价值弹幕 |

### 3.3 容灾方案

- **多机房部署**：主备机房切换
- **服务降级**：关闭非核心功能
- **熔断机制**：异常请求快速失败
- **灰度发布**：新版本逐步放量

## 四、典型问题与解决方案

### 4.1 弹幕卡顿
- **原因**：渲染性能不足或消息积压
- **解决**：启用客户端采样，降低渲染复杂度

### 4.2 消息延迟
- **原因**：网络链路长或服务端处理慢
- **解决**：边缘节点部署，服务端优化

### 4.3 内存泄漏
- **原因**：弹幕对象未正确回收
- **解决**：使用对象池，监听组件销毁

### 4.4 弹幕遮挡
- **原因**：UI层级管理混乱
- **解决**：分通道渲染，固定层级
