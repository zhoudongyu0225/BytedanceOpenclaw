## 二、弹幕游戏 UI/UX 设计最佳实践

### 2.1 弹幕游戏特殊性

弹幕游戏 UI/UX 与普通游戏有本质区别——**游戏状态需要实时透明地传达给主播和观众**，因为观众的弹幕/礼物决策完全依赖可见信息。

**核心设计原则**：
1. **信息不过载**：弹幕量可达1000条/分钟，但视觉通道有限
2. **决策点清晰**：观众需要3秒内理解当前局势
3. **反馈即时可见**：礼物/弹幕效果必须有明确的视觉反馈
4. **主播视角优化**：主播不需要看到所有弹幕细节，需要看到的是战略概览

### 2.2 视觉层级设计

```
┌─────────────────────────────────────────────┐
│  【基地血量条 × 2】              【倒计时】   │  ← 顶层：关键战略信息（固定）
├─────────────────────────────────────────────┤
│                                             │
│              【游戏主画面】                   │  ← 中层：战场实时渲染
│           (塔防/弹幕射击/跑酷等)              │
│                                             │
├─────────────────────────────────────────────┤
│  【弹幕显示区】 ← 滚动弹幕叠加在游戏画面上    │  ← 互动层：观众消息
├─────────────────────────────────────────────┤
│  【礼物弹幕特效】← 大礼物触发全屏特效         │  ← 强调层：重要互动
├─────────────────────────────────────────────┤
│  【小屏：主播/连麦】              【观众列表】 │  ← 底层：辅助信息
└─────────────────────────────────────────────┘
```

### 2.3 弹幕显示策略

**分级展示机制**（解决信息过载）：

| 弹幕类型 | 展示方式 | 优先级 |
|----------|----------|--------|
| 普通弹幕 | 滚动显示，最多保留30条在屏 | 最低 |
| 含关键词弹幕（攻击/防守等） | 高亮+放大，停留2秒 | 中 |
| 大礼物弹幕 | 全屏特效+暂停游戏0.5秒 | 高 |
| 超级弹幕（抖音10级礼物） | 史诗级特效+语音播报 | 最高 |

**滚动弹幕核心参数**：
```javascript
// 推荐配置
const DANMAKU_CONFIG = {
  maxOnScreen: 30,           // 屏幕最多30条滚动弹幕
  maxPerSecond: 5,           // 每秒最多新增5条
  speed: 150,                // 移动速度：像素/秒
  fontSize: 18,              // 普通弹幕字号
  highlightSize: 28,         // 高亮弹幕字号

  collisionDetection: true,   // 碰撞检测，防止重叠
};
```

### 2.4 礼物特效设计

**弹幕游戏礼物特效的特殊性**：
- 礼物特效必须与游戏画面**融合**，不能打断游戏流程
- 特效时长：普通礼物0.5-1秒，超级礼物3-5秒
- 特效需要传达：送礼者昵称 + 礼物名称 + 效果

**典型礼物→游戏动作映射**：
```
小礼物（1-10元）→ 随机增益BUFF（攻击+5%、金币+10等）
中礼物（10-100元）→ 生成小型弹幕怪/小兵
大礼物（100元+）→ 生成Boss级怪物或直接施放技能
超级礼物（平台级）→ 史诗级技能+全屏效果+语音播报
```

## 三、AI NPC 行为响应系统代码框架

### 3.1 三类AI NPC实现层次

根据GDC 2026数据，AI NPC在游戏中的落地分为三个层次：

**第一层：对话层（最简单）**
- NPC能说话，但行为不因对话改变
- 实现：接LLM API → 生成回复文本 → TTS播放
- 局限性：对话与游戏行为脱节

**第二层：参数调整层（中等）**
- AI分析用户行为 → 实时调整游戏参数（难度、付费点频率）
- 实现：埋点采集 → 行为分析 → 参数引擎
- 风险：玩家感知"被操控"，需要有合理的叙事包装

**第三层：行为响应层（最完整）** ← 弹幕游戏最需要的
- NPC理解游戏状态 → 做出合理行为响应
- NPC具有记忆 → 记住与玩家的历史交互
- 实现：游戏状态同步 + LLM推理 + 行为树

### 3.2 弹幕游戏AI NPC代码框架（第三层）

```go
// 弹幕AI NPC行为响应核心架构

package ai

import (
    "context"
    "encoding/json"
)

// GameState 游戏状态快照（由UE4客户端上报）
type GameState struct {
    PlayerHP     int     `json:"player_hp"`
    EnemyCount   int     `json:"enemy_count"`
    Wave         int     `json:"wave"`
    Resources    int     `json:"resources"`
    ActiveEffects []string `json:"active_effects"`
}

// NPCMemory NPC记忆结构
type NPCMemory struct {
    PlayerID      string   `json:"player_id"`
    InteractionCount int   `json:"interaction_count"`
    LastIntent     string   `json:"last_intent"`      // 最近意图
    PlayerLevel    int      `json:"player_level"`
    CumulativeGifts int     `json:"cumulative_gifts"` // 累计打赏
}

// NPCTalkRequest LLM对话请求
type NPCTalkRequest struct {
    NPCID      string      `json:"npc_id"`
    PlayerID   string      `json:"player_id"`
    Content    string       `json:"content"`           // 玩家说的话
    GameState  GameState   `json:"game_state"`        // 当前游戏状态
    Memory     NPCMemory   `json:"memory"`            // NPC记忆
}

// NPCTalkResponse LLM对话响应
type NPCTalkResponse struct {
    Text       string   `json:"text"`         // NPC说的话
    Action     string   `json:"action"`       // 触发的游戏动作
    ActionArgs []string `json:"action_args"`   // 动作参数
    Mood       string   `json:"mood"`          // 情绪状态
}

// DanmakuAI NPC弹幕游戏核心
type DanmakuAI struct {
    llmClient  LLMClient      // LLM接口（VeADK-Go）
    memoryStore *MemoryStore   // 记忆存储
    actionEngine *ActionEngine // 动作引擎
}

// HandleDanmaku 处理单条弹幕
func (d *DanmakuAI) HandleDanmaku(ctx context.Context, danmaku *Danmaku) (*NPCTalkResponse, error) {
    // 1. 获取/更新NPC记忆
    memory := d.memoryStore.Get(danmaku.NPCID, danmaku.PlayerID)
    
    // 2. 构造Prompt
    prompt := d.buildPrompt(danmaku, memory)
    
    // 3. 调用LLM
    resp, err := d.llmClient.Chat(ctx, prompt)
    if err != nil {
        return nil, err
    }
    
    // 4. 解析响应
    npcResp := parseResponse(resp)
    
    // 5. 更新记忆
    memory.InteractionCount++
    memory.LastIntent = npcResp.Action
    d.memoryStore.Set(danmaku.NPCID, danmaku.PlayerID, memory)
    
    // 6. 执行游戏动作
    if npcResp.Action != "" {
        go d.actionEngine.Execute(npcResp.Action, npcResp.ActionArgs)
    }
    
    return npcResp, nil
}

// buildPrompt 构建LLM Prompt
func (d *DanmakuAI) buildPrompt(danmaku *Danmaku, memory *NPCMemory) string {
    return fmt.Sprintf(`你是一名弹幕游戏中的AI队友，名字叫"%s"。
当前游戏状态：
- 玩家血量：%d/%d
- 敌人数量：%d
- 当前波次：%d
- 拥有资源：%d
- 激活效果：%v

与玩家的历史互动：
- 互动次数：%d
- 最近意图：%s
- 玩家等级：%d
- 累计打赏：%d

玩家现在说：%s

请给出符合游戏情境的回复和动作。回复要简洁（不超过20字），动作要具体可执行。
`,
        danmaku.NPCName,
        memory.PlayerHP, 100,
        memory.EnemyCount,
        memory.Wave,
        memory.Resources,
        memory.ActiveEffects,
        memory.InteractionCount,
        memory.LastIntent,
        memory.PlayerLevel,
        memory.CumulativeGifts,
        danmaku.Content,
    )
}
```

#### 4.3.1 弹幕→游戏动作 规则引擎

```go
// servers/logic/control/control_barrage.go 新增

// 弹幕动作映射表
var danmakuActionMap = map[string]DanmakuAction{
    // 方向指令
    "左":   {Action: MOVE, Direction: LEFT, Priority: 1},
    "右":   {Action: MOVE, Direction: RIGHT, Priority: 1},
    "上":   {Action: MOVE, Direction: UP, Priority: 1},
    "下":   {Action: MOVE, Direction: DOWN, Priority: 1},
    
    // 攻击指令
    "攻击": {Action: ATTACK, Priority: 2},
    "打":   {Action: ATTACK, Priority: 2},
    "放":   {Action: ATTACK, Priority: 2},  // 放技能
    
    // 防守指令
    "防":   {Action: DEFEND, Priority: 2},
    "守":   {Action: DEFEND, Priority: 2},
    
    // 特殊指令
    "合体": {Action: SPECIAL, SkillID: 101, Priority: 3},  // 超级技能
    "大招": {Action: SPECIAL, SkillID: 102, Priority: 3},
}

// DanmakuAction 弹幕动作
type DanmakuAction struct {
    Action   string
    Direction string
    SkillID  int
    Priority int
    Cooldown int  // 冷却时间（秒）
}

// ProcessChatMessage 处理弹幕消息（替代todo）
func (c *Controller) ProcessChatMessage(dyMsg *DYLiveMsg) {
    content := dyMsg.Content
    userID := dyMsg.UserID
    
    // 敏感词过滤
    if sensitive.Check(content) {
        return  // 过滤敏感词/广告弹幕
    }
    
    // 查找匹配动作
    action, ok := danmakuActionMap.Match(content)
    if !ok {
        return  // 无匹配，不做动作
    }
    
    // 检查冷却
    if !action.CheckCooldown(userID) {
        return
    }
    
    // 获取玩家
    player := c.GetPlayer(userID)
    if player == nil {
        return
    }
    
    // 权限检查（主播 > 高等级观众 > 普通观众）
    if !action.CheckPermission(player) {
        return
    }
    
    // 设置冷却
    action.SetCooldown(userID)
    
    // 封装为游戏帧消息
    frameMsg := &pb.GameFrame{
        Type:       pb.FrameType_ACTION,
        PlayerID:   userID,
        Action:     action.Action,
        Direction:  action.Direction,
        SkillID:    action.SkillID,
        Timestamp:  time.Now().UnixMilli(),
    }
    
    // 发送到UE4（通过WebSocket）
    c.SendToUE4(player.RoomID, frameMsg)
}
```

// ProcessGiftMessage 处理礼物消息（替代todo）
func (c *Controller) ProcessGiftMessage(giftMsg *DYGiftMsg) {
    giftID := giftMsg.GiftID
    userID := giftMsg.UserID
    giftCount := giftMsg.Count  // 礼物数量
    
    config, ok := giftToUnitMap[giftID]
    if !ok {
        // 未配置礼物，默认生成小兵
        config = &GiftUnit{UnitType: "small_dino", Count: 1, TargetTeam: ENEMY}
    }
    
    // 获取送礼者玩家信息
    player := c.GetPlayer(userID)
    
    // 构造兵种生成消息
    unitMsg := &pb.SpawnUnit{
        Type:        config.UnitType,
        Count:       config.Count * giftCount,
        TargetTeam:  config.TargetTeam,
        SpawnerID:   userID,
        SpawnerName: giftMsg.UserNickname,
    }
    
    // 广播到直播间所有玩家
    c.BroadcastToRoom(giftMsg.RoomID, unitMsg)
    
    // 如果是大礼物，发送特效消息
    if config.UnitType == "boss_dino" || config.UnitType == "special_dino" {
        c.SendGiftEffect(giftMsg.RoomID, giftMsg.UserNickname, config.UnitType)
    }
}

// ai/danmu_review_agent.go

package ai

import (
    "context"
    "fmt"
    "regexp"
    
    veagent "github.com/volcengine/veadk-go/agent/llmagent"
)

type DanmakuReviewResult struct {
    IsPass    bool     `json:"is_pass"`
    Reason    string   `json:"reason"`
    Category  string   `json:"category"`  // spam/ad/malicious/pass
    ReplaceTo string   `json:"replace_to"` // 建议替换内容
}

// DanmakuReviewAgent 弹幕审核Agent
type DanmakuReviewAgent struct {
    agent    *veagent.Agent
    patterns *ReviewPatterns
}

type ReviewPatterns struct {
    URLRegex     *regexp.Regexp
    PhoneRegex   *regexp.Regexp
    SensitiveSet map[string]bool
}

// NewDanmakuReviewAgent 创建弹幕审核Agent
func NewDanmakuReviewAgent() (*DanmakuReviewAgent, error) {
    rootAgent, err := llmagent.New(&llmagent.Config{
        Name:        "danmaku_review",
        Description: "弹幕内容安全审核智能体",
        Instruction: `你是一个严格的弹幕内容审核员。
规则：
1. 广告类内容（链接、联系方式、导流）→ 拦截
2. 敏感词内容 → 拦截或脱敏
3. 恶意刷屏（重复无意义内容）→ 拦截
4. 正常弹幕 → 通过
5. 发现疑似竞品名称 → 标记为风险
输出格式：JSON {is_pass: bool, reason: string, category: string}`,
    },
        llmagent.WithModel("doubao-pro-32k"),
        llmagent.WithTemperature(0.1), // 低温度，高准确性
    )
    
    return &DanmakuReviewAgent{
        agent: rootAgent,
        patterns: &ReviewPatterns{
            URLRegex:   regexp.MustCompile(`https?://[^\s]+`),
            PhoneRegex: regexp.MustCompile(`1[3-9]\d{9}`),
            SensitiveSet: map[string]bool{
                // 实际使用时从文件加载
                "敏感词1": true,
                "竞品名": true,
            },
        },
    }, nil
}

// Review 审核单条弹幕
func (r *DanmakuReviewAgent) Review(ctx context.Context, danmaku string) (*DanmakuReviewResult, error) {
    // 第一层：正则快速过滤
    if r.patterns.URLRegex.MatchString(danmaku) {
        return &DanmakuReviewResult{
            IsPass:   false,
            Reason:   "包含URL链接",
            Category: "ad",
        }, nil
    }
    
    if r.patterns.PhoneRegex.MatchString(danmaku) {
        return &DanmakuReviewResult{
            IsPass:   false,
            Reason:   "包含手机号码",
            Category: "ad",
        }, nil
    }
    
    // 第二层：LLM语义审核（处理复杂情况）
    resp, err := r.agent.Chat(ctx, danmaku)
    if err != nil {
        // LLM不可用时保守放行
        return &DanmakuReviewResult{
            IsPass:   true,
            Reason:   "审核服务不可用，默认放行",
            Category: "pass",
        }, nil
    }
    
    return r.parseLLMResponse(resp)
}

func (r *DanmakuReviewAgent) parseLLMResponse(resp string) (*DanmakuReviewResult, error) {
    var result DanmakuReviewResult
    if err := json.Unmarshal([]byte(resp), &result); err != nil {
        return nil, fmt.Errorf("LLM响应解析失败: %w", err)
    }
    return &result, nil
}
