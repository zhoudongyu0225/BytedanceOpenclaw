### 2.2 UE4 弹幕集成方案

**方案一：嵌入HTTP/WebSocket服务（推荐）**

在UE4客户端内嵌一个轻量HTTP服务（或复用现有WebSocket连接），接收Go服务器推送的弹幕指令：

```cpp
// 伪代码：UE4弹幕指令处理
void UDanmakuManager::OnDanmakuReceived(const FDanmakuCommand& Cmd)
{
    // 弹幕显示
    if (Cmd.Type == EDanmakuType::Display)
    {
        AddDanmakuToScreen(Cmd.Text, Cmd.Color);
    }
    
    // 游戏指令触发（恐龙出兵）
    if (Cmd.Type == EDanmakuType::GameCommand)
    {
        switch (Cmd.Action)
        {
        case EGameAction::SpawnDinosaur:
            SpawnDinosaur(Cmd.PlayerId, Cmd.DinosaurType);
            break;
        case EGameAction::UpgradeTower:
            UpgradeTower(Cmd.PlayerId, Cmd.TowerId);
            break;
        }
    }
}
```

**方案二：通过帧同步数据通道**

弹幕触发逻辑直接走现有的帧同步通道，Go服务器在收到弹幕后生成对应的帧数据：

```
用户弹幕 → Go弹幕服务 → 帧数据生成 → UE4客户端 → 游戏逻辑执行
```
