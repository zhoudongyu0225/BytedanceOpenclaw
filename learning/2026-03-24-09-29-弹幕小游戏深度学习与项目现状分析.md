### 4.1 混合审核架构
```
用户弹幕 → DFA预检(<1ms) → AI语义审核(<200ms) → LRU缓存 → 放行/拦截
```

### 4.2 config.yaml 配置示例
```yaml
model:
  provider: " volcengine"
  model: "doubao-pro-32k"
  api_key: "${VOLC_API_KEY}"
  base_url: "https://ark.cn-beijing.volces.com/api/v3"

agent:
  model:
    completion_window: "30s"
    system_prompt: "你是弹幕游戏内容审核员..."
```

### 4.3 Agent实现要点
- BeforeModelCallback: DFA预检，过滤明显敏感内容
- AfterModelCallback: 解析AI返回JSON，提取pass/reason/level
- LRU缓存: 相同内容缓存，命中率>90%

## 五、P0TODO代码实现路径（2026-03-24确认版）

### 5.1 ChatMessage弹幕逻辑实现框架
```go
// 1. 敏感词过滤
if untils.CheckSensitiveWord(msg.Content) {
    return // 拦截
}

// 2. 弹幕冷却检查
if model.CheckAndSetDanmakuCool(msg.Uid) {
    return // 冷却中
}

// 3. 规则引擎匹配
rule := model.MatchDanmakuRule(msg.Content)
if rule != nil {
    // 扣积分
    model.DeductScore(msg.Uid, rule.ScoreCost)
    // 广播游戏动作
    BroadcastGameAction(msg.Uid, msg.Name, rule.Action)
}

// 4. 消息广播
TipsNotifyBroadcast("GAME_ACTION", msg.Uid, msg.Name, action)
```

### 5.2 GiftMessage礼物逻辑实现框架
```go
// 1. 获取礼物配置
giftConfig := model.GetGiftConfig(msg.GetGiftId())
if giftConfig == nil {
    return
}

// 2. 计算士兵数/救援值
soldiers := computeSoldierNum(giftConfig, msg.GetTotal())
rescue := computeRescueNum(giftConfig, msg.GetTotal())

// 3. 校验礼物价值
if !validateGiftValue(msg.GetTotal(), giftConfig) {
    return // 拒绝异常数据
}

// 4. 增加积分
model.AddScore(msg.Uid, giftConfig.Score)

// 5. 更新周榜/月榜
model.UpdateGameRank(msg.Uid, ws.AnchorV.PlatformId, giftConfig.Score)

// 6. 广播游戏动作
BroadcastGameGift(msg.Uid, msg.Name, msg.GetGiftName(), soldiers, rescue)
```

### 5.3 LikeMessage点赞逻辑实现框架
```go
// 1. 获取点赞数
likeCount := msg.GetCount()

// 2. 点赞冷却检查
if model.CheckLikeCool(msg.Uid) {
    return
}

// 3. 累计点赞
totalLikes := model.AccumLike(msg.Uid, likeCount)

// 4. Buff阈值检查
buffConfig := model.CheckBuffThreshold(totalLikes)
if buffConfig != nil {
    // 触发Buff
    model.SetBuffTriggered(msg.Uid, buffConfig.BuffType)
    // 广播Buff
    BroadcastGameBuff(msg.Uid, msg.Name, buffConfig.BuffType, buffConfig.BuffValue)
}

// 5. 设置冷却
model.SetLikeCool(msg.Uid)
```
